# v1.0.0 · 超天酱/糖糖桌宠

- 修复首次读取配置与默认配置共享对象、损坏配置被直接覆盖的问题。
- 配置与记忆改为原子写入，校验无效分组、位置和关键数值。
- 修复无效记忆记录、零长度历史窗口、模型选项被拆成字符的问题。
- 修改超时与重试设置后，重建对话和视觉客户端。
- 修复配音关闭后仍预热模型、加载失败却标记成功、停止朗读未停止音频的问题。
- 合成网络错误正常收尾，取消过期朗读，设置变更后清理音色缓存。
- 修复打包后素材路径、自启命令与只读安装目录写数据的问题。
- 单实例先占用服务，再创建桌宠；两种版本使用独立实例及数据目录。
- 无 TTS 版移除语音模块、音频依赖与权重，保留双形象、聊天、动画及记忆。
- 默认关闭截屏与自动观察，关闭截屏后手动菜单也不再抓图；视觉降级明确提示无法读取。
- 默认模型更新为官方当前名称 `deepseek-flash`，保留已有用户配置。
- 添加 11 项故障回归，以及源码/EXE 共用的离线界面、资源与线程清理验收。
- 排除构建环境误收集的 Poppler ICU 库，修复发布 EXE 导入 QtWidgets 时启动崩溃。
- 保存状态、关闭自建语音服务后结束主程序，避开 Qt/音频原生库退出清理的偶发崩溃。

默认模型参考：[DeepSeek 官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/)。
